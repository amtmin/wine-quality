# Wine Quality - предсказание качества вина

Учебный проект по Data Science. Цель - пройти путь от сырых данных до работающей модели, которая предсказывает качество вина.

## О проекте
Проект находится в разработке. Сначала - освоение инструментов (Pandas, NumPy, matplotlib), затем - полноценный ML-проект.

## Структура
- `data/raw/` — исходные данные
- `notebooks/` — эксперименты и обучение
- `src/` — финальный код
- `reports/figures/` — графики
- `models/` — сохранённые модели

## Статус
В процессе обучения. Идут эксперименты с библиотеками.
